\section{Experimental Validation}
\label{sec:experiments}

\subsection{Setup}

\textbf{Datasets.} We evaluate across citation, co-authorship, Wikipedia, WebKB, and OGB graphs. Table~\ref{tab:budget_validation} reports the audited subset for which the current artifact contains directly traceable results:
\begin{itemize}
    \item \textit{Citation networks}: Cora, CiteSeer, PubMed (2.7K--20K nodes)
    \item \textit{Co-authorship}: Coauthor-CS, Coauthor-Physics (18K--35K nodes)
    \item \textit{Wikipedia}: Chameleon, Squirrel (2K--5K nodes)
    \item \textit{WebKB}: Texas, Wisconsin, Cornell (183--252 nodes)
    \item \textit{Large-scale OGB}: ogbn-arxiv (169K nodes)
\end{itemize}

\textbf{Models.} MLP (feature-only baseline), GCN \cite{kipf2017gcn}, GAT \cite{velivckovic2018gat}, GraphSAGE \cite{hamilton2017graphsage}, H2GCN \cite{zhu2020beyond}, LINKX \cite{lim2021large}, GPR-GNN \cite{chien2021gprgnn}.

\textbf{Protocol.} Unless noted otherwise, benchmark experiments use 10 random seeds and 60/20/20 train/validation/test splits. The audited ogbn-arxiv result uses the official split and 3 seeds. Several legacy aggregate files do not retain paired per-seed outputs. We report inferential tests only when their underlying samples are present in the audited artifact; otherwise results are treated as descriptive point estimates.

\subsection{Structural Intervention: Edge Shuffle Experiment}

To test whether performance depends on the observed topology, we randomize edges while preserving the degree distribution. This intervention disrupts several graph statistics simultaneously and is therefore evidence of structural dependence rather than a standalone causal identification result.

\subsection{Retrospective Selector Audit}

Historical controlled, leave-one-dataset-out, and external summaries used different prediction targets, favorable tie or abstention scoring, and aggregate files that do not all retain paired seeds. We therefore do not pool their headline accuracies. In the audited six-dataset comparison with one target and matched scoring, the historical rule and an always-graph baseline make the same number of correct selections. This result demonstrates no incremental value for the rule in that comparison. A confirmatory selector evaluation requires a predeclared model set, tie margin, coverage policy, and per-seed outcomes.

\subsection{Decision Algorithm}

\begin{algorithm}[t]
\caption{Diagnostic Workflow for Candidate Model Evaluation}
\label{alg:decision}
\begin{algorithmic}[1]
\REQUIRE Graph $G$, features $X$, labels $Y$
\STATE Train MLP; compute Budget $\mathcal{B} = 1 - \text{Acc}_{\text{MLP}}$
\STATE Compute homophily $h$ and SNR ratio $\kappa = (2h-1)^2 k$
\STATE Always retain MLP as the feature-only reference
\IF{$h < 0.3$}
    \STATE Compute 2-hop ratio $R = h_2/h_1$
    \IF{$R > 1.5$}
        \STATE Flag strong two-hop recovery; benchmark MLP and multi-hop models
    \ELSE
        \STATE Flag absent two-hop recovery; do not infer that structure is useless
    \ENDIF
\ENDIF
\STATE Evaluate candidate graph models on identical splits and seeds
\STATE Report paired differences and uncertainty; abstain from selection when evidence is inconclusive
\end{algorithmic}
\end{algorithm}

Algorithm~\ref{alg:decision} summarizes the diagnostic measurements and candidate-evaluation protocol. The previously frozen binary GNN-versus-MLP rule attained 88.9\% accuracy on the controlled CSBM configurations and 77.8\% on the nine-dataset external set; these finite-sample results do not validate automatic architecture selection.
