\section{SPI-Guided Soft Gating}
\label{sec:spi_fusion}

While the Trust Region framework provides a binary decision rule for architecture selection, real-world applications benefit from a softer, continuous approach. In this section, we propose an SPI-guided soft gating mechanism that dynamically fuses GNN and MLP outputs based on structural predictability.

\subsection{Motivation}

The binary decision algorithm (Algorithm~\ref{alg:spi_decision}) has two limitations:
\begin{enumerate}
    \item \textbf{Hard boundary}: The threshold $\tau$ creates a discontinuous decision boundary, where graphs near $\SPI \approx \tau$ may be misclassified.
    \item \textbf{Single model}: Each graph uses either GNN or MLP, ignoring potential benefits of combining both perspectives.
\end{enumerate}

We address these limitations by introducing a \textit{soft gating} mechanism that smoothly transitions between GNN-dominant and MLP-dominant regimes based on SPI.

\subsection{Soft Gating Formulation}

\begin{definition}[SPI-Guided Soft Gating]
Given node embeddings $\mathbf{Z}_{\text{GNN}}$ from a GNN branch and $\mathbf{Z}_{\text{MLP}}$ from an MLP branch, the fused output is:
\begin{equation}
    \mathbf{Z}_{\text{final}} = \beta \cdot \mathbf{Z}_{\text{GNN}} + (1 - \beta) \cdot \mathbf{Z}_{\text{MLP}}
\end{equation}
where the gating coefficient $\beta$ is computed as:
\begin{equation}
    \beta = \sigma\left(\frac{\SPI - \tau}{T}\right)
\end{equation}
with $\sigma(\cdot)$ being the sigmoid function, $\tau$ the trust threshold, and $T$ the temperature parameter.
\end{definition}

\textbf{Key properties:}
\begin{itemize}
    \item When $\SPI \gg \tau$: $\beta \to 1$, trusting the GNN branch
    \item When $\SPI \ll \tau$: $\beta \to 0$, trusting the MLP branch
    \item When $\SPI \approx \tau$: $\beta \approx 0.5$, equal weighting
    \item Temperature $T$ controls transition sharpness (smaller $T$ = sharper)
\end{itemize}

\subsection{Parameter Selection}

Based on our ablation experiments, we determine optimal parameters:

\textbf{Threshold $\tau$.} From the V2 ablation study, we find $\tau = 0.4$ provides better performance than the originally derived $\tau = 0.67$. This lower threshold allows the fusion mechanism to leverage GNN benefits more aggressively in favorable homophily regions.

\textbf{Temperature $T$.} We use $T_{\text{init}} = 0.15$ as initialization, with $T$ being learnable during training. This allows the model to adapt the transition sharpness to specific datasets.

The architecture consists of three components:
\begin{enumerate}
    \item \textbf{GNN Branch}: Standard GCN/GAT layers that leverage graph structure
    \item \textbf{MLP Branch}: Feature-only MLP layers that ignore structure
    \item \textbf{Soft Gating Module}: Computes $\beta$ from SPI and fuses the two branches
\end{enumerate}

\subsection{Training}

The model is trained end-to-end with cross-entropy loss:
\begin{equation}
    \mathcal{L} = -\sum_{v \in \mathcal{V}_{\text{train}}} \log \hat{y}_v[y_v]
\end{equation}
where $\hat{y}_v = \text{softmax}(\mathbf{Z}_{\text{final}}[v])$.

The temperature $T$ is learned via gradient descent, allowing the model to adapt the gating sharpness. We parameterize $T = \exp(\theta_T)$ to ensure positivity.

\subsection{Practical Guidelines}

For practitioners applying SPI-Guided fusion:

\begin{enumerate}
    \item \textbf{Compute SPI}: Calculate edge homophily and SPI for your graph
    \item \textbf{Initialize}: Start with $\tau=0.4$, $T=0.15$
    \item \textbf{Train}: Allow $T$ to be learned; optionally learn $\tau$ if domain-specific tuning is needed
    \item \textbf{Interpret}: Examine learned $\beta$ values to understand model behavior
\end{enumerate}

\textbf{When to use SPI-Guided Fusion:}
\begin{itemize}
    \item Unknown or uncertain homophily distribution
    \item Datasets near the Trust Region boundary
    \item Applications requiring interpretable model decisions
\end{itemize}

\textbf{When simpler approaches suffice:}
\begin{itemize}
    \item Clear Trust Region ($\SPI > 0.6$): Standard GNN
    \item Clear Uncertainty Zone ($\SPI < 0.2$): MLP
\end{itemize}
