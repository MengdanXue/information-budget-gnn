\begin{abstract}
Graph aggregation can either improve or degrade node classification, and graphs with similar homophily can yield opposite outcomes. We study one mechanism behind this variation: how neighborhood averaging changes class-conditional feature discriminability, and whether simple structural statistics reliably diagnose the resulting performance damage.

Under a binary Gaussian feature model with fixed degree $d$ and conditionally independent neighbor labels, one-hop neighbor averaging has the exact squared-Mahalanobis discriminability ratio $\kappa=\rho^2d/[1+(1-\rho^2)s]$, where $\rho$ is edge-label correlation and $s=\mu^\top\Sigma^{-1}\mu$ is feature strength. The denominator retains label-mixture covariance and shows when the common noise-dominated approximation $\rho^2d$ is inaccurate. This is a moment calculation for a restricted aggregation operator, not a Bayes-error formula, a trained-GNN guarantee, or a new broadcasting threshold.

We complement the calculation with two descriptive measurements: the accuracy difference between an MLP and a graph model, and two-hop label recovery on heterophilic graphs. Audited paired results show that two-hop recovery can expose longer-range label structure but does not determine the best model; in a six-dataset matched-scoring comparison, the retrospective decision rule does not improve on an always-graph baseline. These findings support a scoped mechanism analysis and a negative evaluation of simple diagnostics; $1-\mathrm{Acc}_{\mathrm{MLP}}$ is used only as arithmetic positive-gain headroom.
\end{abstract}
